# Technology Timeline Reference

A technology cannot appear in a role that ended before it existed, and a
product name cannot appear before the product carried that name. Interviewers
who know a stack spot these instantly, and one anachronism costs more
credibility than the keyword gains.

**Rule:** a technology may appear on a role only when it was generally
available for a meaningful part of the role's dates. Announcement or private
preview dates do not count. When a role starts within a year of the date
below, or the technology is not listed, check the project's own release
history before using it; when still in doubt, leave it out.

Dates are first general availability unless noted. Keep the workspace's
tailoring rules as the binding table for the candidate's own roles; this file
is the shared lookup.

## Naming traps

| Name | Valid | Outside that window |
|---|---|---|
| Azure DevOps | from Sep 2018 | VSTS (2015 to 2018), Visual Studio Online, TFS |
| Microsoft Azure | from Mar 2014 | Windows Azure (2010 to 2014) |
| ASP.NET Core, .NET Core | from Jun 2016 | ASP.NET MVC or Web API, .NET Framework |
| .NET Core (product name) | Jun 2016 to Nov 2020 | .NET 5 and later |
| Angular | from Sep 2016 | AngularJS |
| Microsoft Entra ID | from Jul 2023 | Azure Active Directory |
